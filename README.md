# مرآتي — تطبيق المكياج الافتراضي

**الإصدار 1.0.3** — تطبيق ويب عربي لتجربة المكياج مباشرة بالكاميرا أو على صورة محفوظة.

## الوظائف
- تحديد معالم الوجه عبر MediaPipe Face Mesh.
- تخصيص الشدو والكحل والرموش وأحمر الشفاه والبلاشر.
- التقاط الصورة بعد المكياج وحفظها PNG.
- مقارنة قبل/بعد.
- PWA قابل للتثبيت على الهاتف.
- معالجة الصور داخل المتصفح دون رفعها إلى الخادم.

## النشر
مشروع ثابت مناسب لـ Cloudflare Pages. اربط مستودع GitHub واختر **Framework preset: None** و**Build command: فارغ** و**Build output directory: /**.

## حالة الجودة
تم رفع ملفات الإصدار 1.0.3 إلى المستودع. يلزم اختبار الكاميرا ودقة المكياج على أجهزة فعلية قبل اعتماد جودة النتائج. تعتمد مكتبة MediaPipe على تحميل ملفات من jsDelivr عند الاتصال بالإنترنت.
